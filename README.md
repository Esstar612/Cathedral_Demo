# Cathedral of All Saints — website prototype

A static, clickable prototype of a redesigned website for the [Cathedral of All
Saints](https://www.cathedralofallsaints.org/) in Albany, NY, built for the
ITWS-4100 IT Capstone at Rensselaer Polytechnic Institute (Jan–May 2026).

**[Open the showcase →](https://esstar612.github.io/Cathedral_Demo/showcase.html)**

`showcase.html` frames the ten pages side by side with notes on each. The pages
themselves are plain HTML and CSS with no build step — open any of them
directly.

## Pages

| File | Page |
| --- | --- |
| `cathedral-of-all-saints.html` | Home |
| `events.html` | Events index |
| `event-resonant-spirits.html` | Event detail |
| `watch-live.html` | Livestream |
| `give.html` | Giving hub |
| `legacy-of-light.html` | Legacy of Light campaign |
| `friends-of-the-choir.html` | Friends of the Choir |
| `music-department-fund.html` | Music Department Fund |
| `planned-giving.html` | Planned giving |
| `showcase.html` | Viewer for all of the above |

## Notes

This is a prototype, not a deployment. Donation buttons, the livestream player,
and form submissions are all inert. Photography under `img/` is from Unsplash,
served locally so the prototype does not rot when a remote URL moves.

My role on the project was technical liaison to the Cathedral and website lead:
the site architecture research behind the page inventory and navigation, the
software design and engineering document and its UML diagrams, the cost-benefit
analysis, and direction and QA of the visual design. Write-up:
<https://portfolio-three-rose-44.vercel.app/projects/cathedral-of-all-saints>
